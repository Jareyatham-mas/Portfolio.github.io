# Jareyatham Masong Portfolio

A responsive, multi-page personal portfolio with a dark rainforest theme and native browser scrolling.

## Pages

- `index.html` — Home
- `about.html` — About and education
- `projects.html` — Editable project placeholders
- `experience.html` — Work and activity experience
- `tools.html` — Technical tools
- `contact.html` — Social links and email
- `resume.html` — PDF preview and download

## Editing content

Edit `content.js` to change profile information, Thai/English text, project placeholders, tools, and contact links. Project cards are intentionally placeholders until you add project details.

Local assets are stored in `assets/`:

- `jareyatham-profile.gif`
- `Jareyatham-Masong-Resume.pdf`

Open `index.html` in a browser or serve this directory from a local web server. No build tooling or JavaScript dependencies are required.
